# Contributing

Issues and small pull requests are welcome. For larger changes, open an issue first.

1. Run `swift test` and make sure it passes.
2. Never add code that reads sign-in tokens, or that allows commands automatically.
3. Korean is the source language for app text. Add new strings to the table in `Sources/VibeStudio/Support/Localization.swift`, and use the formal `~합니다` style.
