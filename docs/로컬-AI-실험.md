# 로컬 AI (MLX) 시험 기능

API 키나 구독 없이, 이 Mac 안에서 답변을 만드는 기능입니다. 직접 설치판 Condux에만 있습니다.

## 지금까지 확인한 것

| 항목 | 상태 |
| --- | --- |
| 직접 설치판 앱 빌드 | 성공 (MLX 포함) |
| 앱스토어판 앱 빌드 | 성공 (MLX 없음) |
| 모델 파일 크기·지문 | 가장 큰 파일과 설정 파일을 실제 파일과 대조해 일치 확인 |
| 다운로드 끊고 이어받기 | Hugging Face 실제 파일 일부로 확인 |
| 전체 모델 다운로드 | **아직 안 해 봄** |
| 실제 답변 생성, 속도, 메모리, 한국어 품질 | **아직 안 해 봄** |

가짜 엔진 테스트는 통과하지만, 진짜 모델로 답을 만든 적은 아직 없습니다.

## 필요한 것

- Apple Silicon(M1 이후) Mac, macOS 14 이상, 직접 설치판.
- 약 1GB의 저장 공간. 처음 다운로드에만 인터넷이 필요합니다.

앱을 직접 빌드한다면 다음도 필요합니다.

- Xcode ▸ Settings ▸ Components의 **Metal Toolchain**.
- 첫 빌드에서 묻는 플러그인 **CudaBuild**의 **Trust & Enable** 허용. 이 허용을 하기 전에는 명령줄 빌드도 실패합니다.
- 명령줄 빌드에서 Swift 옵션을 넘길 때는 기존 설정을 지우지 않도록 `$(inherited)`를 앞에 붙입니다.

```sh
OTHER_SWIFT_FLAGS='$(inherited) -Xfrontend -disable-sandbox'
```

## 쓰는 순서

1. 설정을 열고 **로컬 AI (MLX) · 시험 기능**을 찾습니다.
2. **모델 다운로드 (약 1GB)**를 누릅니다. 받은 양과 %가 표시됩니다.
3. 끊기거나 중단하면 **이어서 받기**로 받은 곳부터 계속합니다. 다만 오래 지나면 서버 주소가 만료되어 처음부터 받을 수 있습니다.
4. **모델 준비됨**이 보이면 **로컬 새 대화**를 누르고 짧은 질문부터 보냅니다.

오류가 나거나 모델이 없어도 유료 API로 자동 전환하지 않습니다.

## 할 수 있는 것과 없는 것

- 모델: `mlx-community/Qwen3-1.7B-4bit`. 작은 시험용 모델이라 한국어와 코딩 답변이 부정확할 수 있습니다.
- 됩니다: 글 대화, 답변 스트리밍, 중단, 저장된 대화 이어 쓰기.
- 안 됩니다: 첨부, MCP, 명령 실행, 작업 폴더, 릴레이, 답변의 파일 블록을 파일로 저장하기.
- 한도: 대화 전체 8,000자, 답변 512토큰. 긴 답변은 잘릴 수 있습니다.

## 안전장치

- 다운로드는 버튼을 눌렀을 때만 시작합니다. 대화 내용은 어디로도 보내지 않습니다.
- 버전을 고정하고, 파일마다 크기와 SHA-256을 확인합니다. 하나라도 틀리면 받은 파일을 모두 지웁니다.
- 답변을 만들 때는 내려받은 폴더의 파일만 읽고, 인증 토큰 없는 오프라인 설정을 씁니다.
- 모델은 앱 데이터 폴더의 `Models/qwen3-1.7b-4bit`에 둡니다. **모델 삭제**는 이 폴더와 받다 만 파일만 지우고 대화 기록은 남깁니다.
- 답변마다 모델을 불러오고, 끝나면 참조와 MLX 캐시를 해제합니다.
